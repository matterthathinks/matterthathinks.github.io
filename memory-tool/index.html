Squares, 1–25 — and how to get to 100 without memorising them

Memorise 1–25 cold. Past that, you don't recall — you compute, in about two seconds, from an anchor.

The anchor method

Every square from 25 to 100 is one algebra identity away from a number you already know: (a ± k)² = a² ± 2ak + k². Pick the nearest multiple of 25 as your anchor a, let k be the small distance to it, and you're doing single-digit arithmetic.

Ending in 5

For any n5², take n, multiply by (n+1), append "25".

35² → 3×4=12 → 1225. 65² → 6×7=42 → 4225.

Anchor at 25 (26–49)

(25+k)² = 625 + 50k + k²

27² → 625+50(2)+4 = 729

Anchor at 50 (33–66)

(50±k)² = 2500 ± 100k + k²

47² → 2500−100(3)+9 = 2209

Anchor at 75 (63–87)

(75±k)² = 5625 ± 150k + k²

78² → 5625+150(3)+9 = 6084

Anchor at 100 (76–100+)

(100−k)² = 10000 − 200k + k²

97² → 10000−200(3)+9 = 9409

Difference of squares

a² − b² = (a−b)(a+b). Handy when a number is 1 or 2 away from something square-friendly.

29² = 30²−(30+29) = 900−59 = 841

Cubes, 1–20

There's no shortcut as clean as the squares one — so this list is worth rote-learning in full. A few things make it easier.

What actually helps

Last-digit pairs

Cubes preserve a predictable last digit, and it pairs numbers up: 1↔1, 2↔8, 3↔7, 4↔4, 5↔5, 6↔6, 7↔3, 8↔2, 9↔9, 0↔0. Useful for a sanity check on any answer.

Binomial expansion

(a+b)³ = a³ + 3a²b + 3ab² + b³

13³ = 10³+3(100)(3)+3(10)(9)+27 = 1000+900+270+27 = 2197

Sum-of-cubes identity

1³+2³+…+n³ = (n(n+1)/2)². Won't give a single cube, but it's a free check when a question asks for a running sum.

Anchor at 10 and 20

Cubes near 10 or 20 are cheapest via the binomial rule above — the a³ and 3a² terms only need computing once per anchor.

Fractions → percentages, 1/x to 5/x for x up to 30

This table is the one that actually shows up under time pressure — DI sets, CAGR sanity checks, quick margin math. Reading down a column is reading off n/x for a fixed x.

How to get there without memorising all 100+ cells

Halving chain

1/x for a doubled denominator is just half the previous percentage. Learn 1/2 → 1/4 → 1/8 → 1/16 as one chain, and 1/3 → 1/6 → 1/12 → 1/24 as another.

1/8=12.5% → 1/16=6.25%. 1/6=16.67% → 1/12=8.33% → 1/24=4.17%.

The 1/7 doubling trick

1/7 = 14.28...%. To get there: 7×2=14, 14×2=28 — that's your first four digits, "14.28", straight from doubling 7 twice.

Divide 1/7 by n

Every 1/(7n) is 1/7 divided by n — cheaper than computing fresh.

1/14 = 14.28/2 = 7.14%. 1/21 = 14.28/3 = 4.76%. 1/28 = 14.28/4 = 3.57%.

The 3-4-5 anchor

1/23 ≈ 4.35% and 1/29 ≈ 3.45% — the digits 4-3-5 and 3-4-5 are a Pythagorean triplet, which is purely a mnemonic, not a derivation, but it sticks.

n/x from 1/x

Don't memorise 2/19, 3/19, 4/19 separately — get 1/19 = 5.26% once, then just multiply by n.

1/19=5.26% → 3/19=15.79% (×3)

Increase ↔ equivalent decrease

If a quantity goes up by n/x, reversing it back down isn't the same percentage — it's n/(x+n). Constant-product situations (Time×Speed, Quantity×Price) use this directly.

+50% (1/2) reverses with −33.33% (1/3), not −50%.
